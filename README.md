# 📊 Google Play Store Data Analysis using Power BI

## 📌 Project Overview

This project focuses on analyzing **Google Play Store application data** using **Microsoft Power BI**. The objective is to transform raw app data into meaningful insights through data cleaning, transformation, data modeling, DAX calculations, and interactive dashboards.

The dashboard helps analyze application performance based on **ratings, reviews, categories, pricing, app size, content rating, and installation-related metrics**.

---

## 🎯 Project Objectives

* Analyze Google Play Store app performance.
* Identify trends across different app categories.
* Analyze app ratings and reviews.
* Compare free and paid applications.
* Study app pricing and app size.
* Understand content-rating distribution.
* Identify patterns in app installations.
* Create an interactive and user-friendly Power BI dashboard.

---

## 🔄 Data Preparation

The raw dataset was prepared using **Power Query**.

The major data-cleaning steps included:

* Removing duplicate records
* Handling missing values
* Cleaning numerical fields
* Converting data types
* Cleaning price and size values
* Transforming installation values
* Standardizing categorical data
* Preparing data for visualization
